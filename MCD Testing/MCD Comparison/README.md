This is a comparison of MCDs generated in Machine Setup (Studio) vs. **CalculateParameters** method



I've included a Python script to run an MCD compare tool that displays the differences between the files. It will ask you to navigate to both files...The Studio MCD should be chosen first. Of course, you may have something more intelligent that does this already.



You will see that even when the **GenerateMCD.py** (workflow 1) is successful, the resulting MCD does not have any parameter values. This was confirmed by looking at the extracted files and using the MCD compare tool in Studio.
